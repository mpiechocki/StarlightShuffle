# Starcatchers art (originals)

The approved original from the Starcatchers reference, kept for re-exporting;
this folder is outside `assets/`, so the build does not ship it.

- `galaxy-sky.png`: the galaxy backdrop with the ringed planet, shipped as is in
  `assets/textures/starcatchers/galaxy.png`. `galaxy-sky-prompt.txt` records its
  art direction.

Stars, constellations, satellites, the moon platforms and the hand net are
drawn in code (`minigames/starcatchers/Art.luau`), after the reference
renderer's flat polygon shapes. The reference's three avatar PNGs were
placeholders and are not used: everyone is drawn from their own outfit.
