# Pillow Fight art (originals)

The approved originals from the Pillow Fight prototype, kept for re-exporting.
This folder is outside `assets/`, so the build does not ship it.

- `sky-bedroom.png`: the generated dreamy bedroom backdrop; shipped as is in
  `assets/textures/pillow_fight/bedroom.png`.
- `pillow.svg`: the plump stitched pillow. The game draws the same paths in
  `minigames/pillow_fight/Art.luau` (held pillows, flying pillows, the Throw
  button and the how-to examples), so there is no raster copy.

`assets/textures/pillow_fight/doll-1.png` to `doll-3.png` are the prototype's
three demo avatars. The game uses them only for filler bots (always labelled
"· bot"); every human is drawn from their own outfit.
